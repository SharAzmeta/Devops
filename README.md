# SimpleTask API — веб‑приложение на Node.js

> **Описание проекта:** SimpleTask API — это минималистичное веб-приложение на Node.js, позволяющее создавать, просматривать и удалять задачи через REST API. Проект предназначен для обучения базовой серверной разработке, работе с маршрутами и структурой Node.js-приложений.

---

## 🎯 Цели проекта

* 1. Освоить создание простого HTTP‑сервера на Node.js.
* 2. Понять принципы построения REST API.
* 3. Научиться работать с маршрутизацией и обработкой запросов.
* 4. Подготовить основу для более сложных сервисов.

## 🚀 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/username/simpletask-api
cd simpletask-api

# Установка зависимостей
npm install

# Запуск сервера
npm start
```

После запуска сервер доступен по адресу: **[http://localhost:3000](http://localhost:3000)**

---

## 📌 Основные маршруты API

* `GET /tasks` — получить список задач.
* `POST /tasks` — создать новую задачу.
* `DELETE /tasks/:id` — удалить задачу по ID.

## 🧪 Тестирование

Чтобы протестировать работу API:

* Убедитесь, что приложение запущено.
* Используйте любой инструмент тестирования API (например, **Postman**, **Insomnia** или `curl`).
* Проверьте корректность следующих операций:

  * Получение списка задач.
  * Создание новой задачи.
  * Удаление задачи.
* Если используете `npm test`, убедитесь, что тесты добавлены в проект.

Пример проверки через `curl`:

```bash
curl http://localhost:3000/tasks
```
